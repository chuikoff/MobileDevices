Description:
============
Total Commander file system plugin (WFX) for Android phones (MTP /
Windows Portable Devices) and iPhone/iPad (Apple Devices from Microsoft
Store).

- Browse, copy, move, delete, rename and create folders
- Device info: model, battery, free/capacity (Alt+Enter or quote info)
- iPhone: Photos, Applications (File Sharing), Panic Logs
- Commands: quote refresh, quote eject, quote info, quote reconnect

Requirements:
=============
Windows Vista or later with Windows Portable Devices (WPD) support.
iPhone support needs Apple Devices (Microsoft Store) and 64-bit
Total Commander.

Installation:
=============
Open the plugin archive in Total Commander (or double-click it from TC).
Files: mtpdevices.wfx (32-bit) and mtpdevices.wfx64 (64-bit).

The plugin shows up in Network Neighborhood as "MTP Devices".
Timezone settings (Alt+Enter on the device) are stored under [MTPDevices].
